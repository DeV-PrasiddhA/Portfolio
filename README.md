# Prasiddha Mainali — Portfolio

Professional portfolio with an interactive 3D neural sculpture, selected AI projects, experience, awards, and writing.

## Preview locally

Run `python -m http.server 8000` from this repository, then open http://localhost:8000.

## Structure

- `index.html`: homepage, experience, awards, contact links
- `style.css`: shared design and responsive layouts
- `app.js`: project dialogs and clipboard controls
- `scene.js`: shared 3D neural field and interactive pathways
- `experience.css`: premium visual layer and neural controls
- `experience.js`: two procedural scores, audio controls, entrance and journal interactions
- `icon.svg`: current favicon
- `blogs.html`: filterable journal index
- `blogs/`: eight articles
- `writing.css`: article layouts
- `sitemap.xml`: sitemap for the existing Render domain

## Deployment

This is a static website with no build step. Publish the repository root (`.`), not a `dist` folder. The existing root layout is preserved for Render and GitHub Pages. No server, npm installation, API keys, or secrets are required. Google Fonts is optional; system fonts provide fallbacks.

## Features

- WebGL-rendered 3D neural field with gentle pointer parallax, interactive pathways, and motion controls
- Reduced-motion support and responsive layouts
- Accessible project dialogs and working email/social links
- Updated National Rank 2 and IOAI Honorable Mention
- Two preserved articles and six new essays / humor pieces with category filters and reading progress

Project artwork is illustrative, not product screenshots. Nidaan is credited as a collaborative/forked project. Contact uses email links rather than an unconnected form.

Previous website files remain recoverable through Git history.


## Premium interactive edition

The original charcoal, ivory, and muted-gold visual design is restored. A single full-screen WebGL neural field continues behind the landing screen and portfolio, with reduced-motion support, a motion toggle, and a static fallback. The field is an abstract brain-like geometry, not an anatomical model.

Audio is enabled by default for new sessions, with a remembered session mute preference. Browsers that restrict autoplay start it on the first click/key interaction; the landing offers a direct listen button as well. Two original procedurally composed scores use different tempos, harmonies, and patterns, with a crossfade when entering or replaying the introduction. Volume and mute controls remain accessible, and audio suspends in hidden tabs. No external audio downloads or services are required.

The eight-article journal is retained. The two humorous posts are fictional.

## A lasting visual identity

The neural field uses three pathways—Wonder, Connect, Create—to represent curiosity, finding relationships, and turning understanding into useful work. Selecting a pathway softly highlights a traveling signal through the same sculpture. These ideas do not depend on age, current job titles, frameworks, or a changing list of skills. The biography, projects, and milestones can evolve independently of the visual identity.

The 3D field is drawn locally, without external models, animation services, or video downloads. Three small static path buffers add signals to the existing renderer. The 30 fps cap, limited pixel density, hidden-tab suspension, reduced-motion preference, manual pause, and static fallback are retained. Colors and foreground shading keep the sculpture visible while protecting text contrast.

No website can be guaranteed maintenance-free for decades; future browser or hosting changes may still require attention. This separates long-lived design from the content that naturally changes over time.
